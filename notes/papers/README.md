# 论文笔记

## 阅读顺序

1. SRCNN — 图像超分开山工作
2. ESPCN — 亚像素卷积、实时超分
3. VDSR — 深层超分、残差
4. BasicVSR — 视频超分的时序传播
5. RAFT — 光流估计
6. TAA / TAAU 相关资料 — 时序累积与 jitter

## 要求

- 每篇先写 5 行摘要，再决定要不要精读。
- 不追求完整复现，先复现核心模块。
- 记录“它为什么有效”和“它的代价是什么”。
