# 阶段学习指南

这里的每份文档对应 **一个 2–3 个月的学习阶段**，不是按天拆分。

## 节奏约定

- 每个阶段结束，更新一份学习清单：**这个阶段用到了什么，你要补什么，怎么算学会**。
- 清单只写"当前阶段用得到"的知识，不做系统补课（见 `docs/learning_path.md` 的原则）。
- 学完一个阶段，找我做**口述题 + 现场改代码**验收，过了才进下一阶段。
